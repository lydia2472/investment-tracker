## 功能概述

投资账户管理系统是一个功能完整的个人财务管理工具，主要功能包括：

### 核心功能

1. **多账户管理**
   - 支持证券、银行、现金、其他四种账户类型
   - 自定义账户颜色标识
   - 实时查看账户余额和变动

2. **交易记录**
   - 记录收入、支出、转账、快照四种交易类型
   - 自动关联账户并更新余额
   - 支持交易描述和备注

3. **智能转账**
   - 一键完成账户间转账
   - 自动生成转出和转入两条交易记录
   - 自动更新双方账户余额

4. **数据统计**
   - 账户资产分布饼图
   - 收入支出对比柱状图
   - 余额趋势折线图

5. **本地存储**
   - 数据保存在浏览器 localStorage
   - 无需联网，数据完全私有
   - 支持导出备份

## 快速开始

### 第一步：创建账户

1. 点击左侧导航菜单的「账户」
2. 点击右上角「添加账户」按钮
3. 填写账户信息：
   - **账户名称**: 例如"招商银行"、"股票账户"
   - **账户类型**: 选择证券、银行、现金或其他
   - **初始余额**: 输入账户当前余额
   - **币种**: 选择 CNY、USD、EUR 或 HKD
   - **颜色标识**: 选择一个颜色用于图表展示
   - **描述**: 添加备注信息（可选）
4. 点击「创建」完成账户创建

### 第二步：记录交易

1. 点击左侧导航菜单的「交易」
2. 点击右上角「添加交易」按钮
3. 填写交易信息：
   - **账户**: 选择交易关联的账户
   - **交易类型**: 选择收入、支出或快照
   - **分类**: 根据交易类型选择相应分类
   - **金额**: 输入交易金额
   - **描述**: 添加交易描述
   - **备注**: 添加详细信息（可选）
4. 点击「添加」完成交易记录

### 第三步：查看统计

1. 点击左侧导航菜单的「统计」
2. 查看三个标签页：
   - **账户分布**: 查看各账户资产占比
   - **收支分析**: 对比总收入和总支出
   - **余额趋势**: 查看资产变化曲线

## 账户管理

### 账户类型说明

系统支持四种账户类型，每种类型适用于不同的理财场景：

#### 1. 证券账户 (SECURITIES)

适用于：股票账户、基金账户、理财账户等投资账户

- 示例：华泰证券、蚂蚁基金、天天基金

#### 2. 银行账户 (BANK)

适用于：储蓄卡、信用卡、定期存款等银行账户

- 示例：招商银行、工商银行、建设银行

#### 3. 现金 (CASH)

适用于：现金、钱包、零钱等

- 示例：现金钱包、红包余额

#### 4. 其他 (OTHER)

适用于：无法归入上述类型的账户

- 示例：借条、应收账款、虚拟货币

### 创建账户

1. 进入「账户」页面
2. 点击右上角「添加账户」按钮
3. 填写完整信息（所有必填项都有 \* 标记）
4. 点击「创建」保存

**提示**：初始余额是账户创建时的余额，之后会根据交易自动更新。

### 编辑账户

1. 在账户列表中找到要编辑的账户
2. 点击账户卡片右上角的「⋮」菜单图标
3. 选择「编辑」
4. 修改信息后点击「保存」

**注意**：编辑账户会重置余额为新的初始余额，谨慎操作。

### 删除账户

1. 在账户列表中找到要删除的账户
2. 点击账户卡片右上角的「⋮」菜单图标
3. 选择「删除」
4. 确认删除操作

**警告**：删除账户会同时删除该账户的所有交易记录，且无法恢复！

### 账户颜色标识

每个账户都可以选择一个颜色标识，该颜色用于：

- 图表中的账户标识
- 总览页面的账户图标
- 交易记录中的账户标记

系统提供 8 种预设颜色：

- 蓝色 `#3b82f6` - 默认颜色
- 绿色 `#10b981` - 适合收入型账户
- 琥珀色 `#f59e0b` - 适合储蓄账户
- 红色 `#ef4444` - 适合支出型账户
- 紫色 `#8b5cf6` - 适合投资账户
- 粉色 `#ec4899` - 适合特殊用途
- 靛蓝色 `#6366f1` - 适合银行账户
- 青色 `#14b8a6` - 适合现金账户

## 交易记录

### 交易类型

系统支持四种交易类型，每种类型有不同的用途：

#### 1. 收入 (INCOME)

记录账户的收入增加，可用分类：

- **存款**: 银行存款、现金存入
- **转入**: 从其他账户转入（通常由转账功能自动生成）
- **投资收益**: 股票收益、基金分红、利息收入

**效果**: 账户余额增加

#### 2. 支出 (EXPENSE)

记录账户的支出减少，可用分类：

- **取款**: 银行取款、现金支出
- **转出**: 转出到其他账户（通常由转账功能自动生成）
- **投资亏损**: 股票亏损、投资损失

**效果**: 账户余额减少

#### 3. 转账 (TRANSFER)

在账户间转移资金

**注意**: 转账会自动创建两条交易记录：

- 转出账户：支出类交易（TRANSFER_OUT）
- 转入账户：收入类交易（TRANSFER_IN）

#### 4. 快照 (SNAPSHOT)

记录某个时间点的账户余额，不影响实际余额

**用途**: 定期记录资产状况，用于对比历史数据

### 添加交易

#### 收入/支出交易

1. 进入「交易」页面
2. 点击「添加交易」按钮
3. 选择交易类型：收入或支出
4. 填写信息：
   - **账户**: 选择关联账户
   - **交易类型**: 收入/支出
   - **分类**: 选择对应的分类
   - **金额**: 输入金额
   - **描述**: 简短描述
   - **备注**: 详细说明（可选）
5. 点击「添加」

#### 快照交易

1. 进入「交易」页面
2. 点击「添加交易」按钮
3. 选择交易类型：快照
4. 填写信息：
   - **账户**: 选择要记录的账户
   - **快照余额**: 输入当前余额
   - **描述**: 例如"月末余额"、"季度盘点"
5. 点击「添加」

### 转账操作

转账功能可以自动在两个账户间转移资金：

1. 进入「交易」页面
2. 点击「转账」按钮
3. 填写转账信息：
   - **从账户**: 选择转出账户
   - **到账户**: 选择转入账户（不能与转出账户相同）
   - **转账金额**: 输入转账金额
   - **描述**: 转账说明（例如"生活费转账"）
4. 点击「确认转账」

**自动处理**：

- 系统会自动创建两条交易记录
- 转出账户余额减少
- 转入账户余额增加
- 两条记录自动关联，方便追踪

### 查看交易历史

1. 进入「交易」页面
2. 所有交易按时间倒序排列（最新交易在最前）
3. 每条交易显示：
   - 日期
   - 关联账户
   - 交易类型标签
   - 交易分类
   - 描述和备注
   - 金额（收入显示绿色+，支出显示红色-）

### 编辑/删除交易

1. 在交易列表中找到目标交易
2. 点击交易行最右侧的「⋮」菜单图标
3. 选择「编辑」或「删除」
4. 根据提示完成操作

**注意**：

- 编辑交易会更新关联账户的余额
- 删除交易会恢复账户余额到交易前的状态
- 转账产生的两条交易需要分别编辑或删除

## 统计分析

### 账户分布

**位置**: 统计页面 → 账户分布标签页

**功能**：

- 显示各账户资产占比的饼图
- 鼠标悬停查看具体金额
- 百分比标签显示账户占比

**用途**：

- 了解资产配置情况
- 识别占比较大的账户
- 优化资产分配

### 收支分析

**位置**: 统计页面 → 收支分析标签页

**功能**：

- 对比总收入和总支出的柱状图
- 绿色柱：总收入
- 红色柱：总支出
- 鼠标悬停查看具体金额

**计算方式**：

- 总收入 = 所有收入类交易的金额之和
- 总支出 = 所有支出类交易的金额之和

**用途**：

- 评估收支平衡状况
- 识别收支比例问题
- 制定预算计划

### 余额趋势

**位置**: 统计页面 → 余额趋势标签页

**功能**：

- 显示随时间变化的余额曲线
- X轴：日期
- Y轴：余额
- 鼠标悬停查看具体日期的余额

**数据来源**：

- 基于所有交易按日期汇总
- 收入交易增加余额
- 支出交易减少余额

**用途**：

- 追踪资产增长趋势
- 识别财务变化拐点
- 预测未来走势

## 数据备份与恢复

### 数据存储位置

系统使用浏览器的 localStorage 存储数据：

- **账户数据**: 键名 `account-storage`
- **交易数据**: 键名 `transaction-storage`

### 导出备份

1. 打开浏览器开发者工具（F12）
2. 进入「应用程序」或「Application」标签页
3. 左侧选择「本地存储」或「Local Storage」
4. 选择您的网站域名
5. 找到以下键并复制其值：
   - `account-storage`
   - `transaction-storage`
6. 将值保存为文本文件（建议命名为 `backup-account.json` 和 `backup-transaction.json`）

### 导入恢复

1. 打开浏览器开发者工具（F12）
2. 进入「控制台」或「Console」标签页
3. 执行以下命令导入数据：

```javascript
// 导入账户数据
localStorage.setItem('account-storage', '粘贴您的账户数据 JSON')

// 导入交易数据
localStorage.setItem('transaction-storage', '粘贴您的交易数据 JSON')

// 刷新页面
location.reload()
```

### 清除所有数据

如需清除所有数据并重新开始：

1. 打开浏览器开发者工具（F12）
2. 进入「应用程序」或「Application」标签页
3. 左侧选择「本地存储」或「Local Storage」
4. 选择您的网站域名
5. 点击「清除全部」或逐个删除键值对

**警告**: 清除数据将无法恢复！

## 常见问题

### 1. 为什么我的账户余额没有更新？

**可能原因**：

- 交易记录时选择了错误的账户
- 交易类型选择错误（收入/支出混淆）

**解决方法**：

1. 检查交易记录中的账户是否正确
2. 验证交易类型是否符合预期
3. 如有错误，编辑或删除相关交易

### 2. 转账后为什么有两条交易记录？

**正常现象**：

- 转账功能会自动创建两条交易
- 一条在转出账户（支出类）
- 一条在转入账户（收入类）
- 这样可以保证两个账户的余额都正确更新

### 3. 删除账户会怎样？

**影响**：

- 账户本身被删除
- 该账户下的所有交易记录也被删除
- 其他账户不受影响

**建议**：

- 删除前确认该账户的交易记录不再需要
- 重要账户建议只编辑不删除

### 4. 如何修改已记录的交易？

**步骤**：

1. 进入「交易」页面
2. 找到要修改的交易
3. 点击交易行右侧的「⋮」菜单
4. 选择「编辑」
5. 修改信息后保存

**注意**：

- 编辑金额会更新关联账户余额
- 修改账户会从原账户扣除、向新账户增加

### 5. 数据会丢失吗？

**安全措施**：

- 数据保存在浏览器本地，不依赖网络
- 只要不清除浏览器数据，数据会一直保留
- 建议定期导出备份

**风险情况**：

- 清除浏览器缓存和数据
- 换电脑或浏览器
- 重装系统

**预防措施**：

- 定期导出数据备份（见上文）
- 使用浏览器同步功能（如果支持）

### 6. 支持多币种吗？

**支持情况**：

- 可以创建不同币种的账户
- 金额会按账户币种显示
- 但所有金额按数字大小累加，不考虑汇率

**建议**：

- 如果有多币种需求，建议为不同币种创建独立的账户
- 在账户名称中标注币种，例如"美元账户"

### 7. 可以在手机上使用吗？

**可以**：

- 系统采用响应式设计，支持手机、平板、电脑
- 界面会自动适配屏幕大小
- 所有功能在移动设备上完整可用

**建议**：

- 在手机浏览器上添加到主屏幕，体验类似原生应用

### 8. 如何快速定位某个交易？

**方法**：

- 使用浏览器搜索功能（Ctrl+F / Cmd+F）
- 搜索交易描述、账户名称、金额等关键词
- 交易列表按时间排序，新交易在前

### 9. 收支统计不准确？

**检查项**：

1. 确认所有交易都已记录
2. 检查交易类型是否正确（收入/支出）
3. 查看是否有遗漏的交易
4. 验证金额是否输入正确

### 10. 如何批量删除交易？

**当前版本**：

- 需要逐个删除交易
- 点击每条交易的「⋮」菜单，选择删除

**未来改进**：

- 计划添加批量删除功能
- 支持按日期范围、账户、类型筛选后批量操作
