# 应用图标

此目录需要存放应用图标文件。

## 需要的图标文件

### icon.png (1024x1024)
通用应用图标，PNG 格式，建议尺寸 1024x1024 像素。

### icon.icns
macOS 应用图标。

可以使用在线工具将 PNG 转换为 ICNS：
- https://cloudconvert.com/png-to-icns
- https://www.img2icnsapp.com/

### icon.ico (可选)
Windows 应用图标。

## 临时方案

在自定义图标准备好之前，Electron 会使用默认图标。

## 设计建议

- 使用简洁的金融/投资相关图标
- 主色调：蓝色 (#3b82f6) 或绿色 (#10b981)
- 背景：纯色或渐变
- 风格：扁平化或现代简约风格
